# Как использовали ИИ

ИИ участвовал в реализации Java-генератора, подготовке тестов и проверке сборки. Ниже приведены примеры работы, которые можно воспроизвести при демонстрации.

| Что проверяли | Пример | Ожидаемый результат |
|---|---|---|
| Кратность букв | БАРАН и БАРБАР для БАРАБАН | БАРАН подходит. Для БАРБАР не хватает второй Р. |
| Нормализацию слов | ЛЁН и ЛЕН для КЛЁН | В результат входит ЛЁН. |
| Порог прохождения | Два подходящих подслова при пороге 2 | Генератор сохраняет уровень. |
| Работу с большим словарём | 100 000 синтетических записей и одно подходящее слово | Тест проверяет результат и выводит время выполнения. |

При сборке ИИ обнаружил пропущенный импорт Scanner, добавил его и проверил запуск JAR на Java 8. Для демонстрации подготовлены входной JSON, ожидаемый результат и снимок окна Swing.

## Фрагменты переписки

**Пользователь:** «Это если что нужно на Java делать. Ты на Java сделал?»

**Ответ:** «Первую версию я сделал на JavaScript. Перепишу генератор на Java и проверю его на тех же девяти сценариях.»

**Пользователь:** «Ты короче его называй типа русскими словами метод, но английскими буквами, чтобы можно было прочитать русскими.»

**Результат правки:** основной метод получил имя sozdatUrovni, подсчёт букв — podschitatBukvy, проверка кратности — khvataetBukv.
